# STUDENT GRADING SYSTEM
## Overview

This project titled "Student Grading System** is a simple , menu-driven Python application made for teachers to manage scores and marks of students.
It uses Python data structures, the system stores each student's marks (out of 100) and assign them grades based on there score  (`A`–`F`). 

## Features

- **Add Student Marks:** Teacher can add name of student and there respective marks(out of 100).
- **Update Student Marks:** Teacher can update entered student marks .
- **Delete Marks :** Teacher can remove data .
- **View All Marks:** Display data of all student.
- **Individual Grade Lookup:** Search and display grades and marks and name.
- **Class Average Analytics:** Calculate class average .
- **Menu-Driven Interface:** Project has a very Simple interface .

## Tools Used
- **Language** Python
- **Code editor** VS code
- **Version Contron** Github




## Instructions

When you run the program, a menu will display with numerical options. Enter the corresponding number to perform an action:

1. **Add Student Information (Option 1)**
   - Enter the student's name when prompted.
   - Enter their numerical marks out of 100.
   - The system validates the marks and automatically assigns a letter grade (`A`, `B`, `C`, `D`, or `F`).

2. **Update Student Information (Option 2)**
   - Enter the name of the existing student.
   - Enter their new marks (0–100).
   - The grade will be automatically recalculated and updated.

3. **Delete Student Information (Option 3)**
   - Enter the name of the student you wish to remove from the system.

4. **View All Student Records (Option 4)**
   - Displays a full list of all recorded students along with their marks and letter grades.

5. **View Individual Grade (Option 5)**
   - Enter a student's name to display their specific marks and letter grade.

6. **Calculate Class Average (Option 6)**
   - Calculates and displays the overall class average marks and the average letter grade.

7. **Exit Program (Option 7)**
   - Terminate and close the application.
